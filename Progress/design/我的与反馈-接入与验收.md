2026-10-27，美国东部时间。用户在确认J版方向后授权直接接入小程序，后续逐项反馈作为本文件当前依据。J版HTML保留为历史样稿，不覆盖并行设计目录。

## 页面与入口

- 首页辅助入口共用一行：左侧歌单自适应，右侧“我的”为112rpx正方形，同高、同圆角；删除重复页脚入口，保留原歌单/往期跳转参数。
- 我的：显示称呼、首次使用日期、本周点歌、外观、反馈中心、关于。不接图鉴、称号、长期足迹和背景图片。
- 关于归入我的，保留介绍/版本、使用说明、管理员验证和底部隐私/署名；反馈改走小程序内反馈中心。
- 反馈中心：500字文本、三类反馈、独立历史页与处理回复；功能投票为2–4选项单选，截止前可改票，投后/结束后看结果。
- 超管管理：状态筛选、按稳定用户编号查看、回复/处理状态、创建与结束投票。普通管理员原审核、验证码和数据管理职责不变。

## 本周卡片

| 显示状态 | 主要动作 |
| --- | --- |
| 初次加载 | 常驻卡片内显示简短读取状态，不显示灰色禁用按钮块 |
| 读取失败且无快照 | 明确失败，提供重试，不猜测未提交或通道状态 |
| 未投稿、通道开放 | 回首页点歌 |
| 未投稿、通道关闭 | 只显示个人记录摘要，通道时间在首页查看 |
| 已投稿、通道开放 | 查看本人提交；无需再次提交 |
| 已投稿、通道关闭 | 保留提交记录入口 |
| 歌单已发布 | 查看本期歌单；有本人记录时按submission_id核对，待审核selected不能提前宣称入选 |

周期口径与首页一致：正常关闭时看最新歌单期，临时开放时看当前投稿周期，强制关闭优先。发表后没有本人记录不能据此断言从未提交。

第一次成功后只在当前小程序会话内保存快照，按测试/正式域隔离。返回、重建页面先呈现已有快照，后台刷新；有变化才替换业务内容，失败保留旧内容并说明，跨周不沿用旧卡片。没有把本人投稿和账号身份长期落盘。

## 称呼与首次使用

- 称呼字段为现有users/test_users.name_alias，默认“点歌同学”。服务端只更新该字段，不改变openid、角色、积分或创建时间。
- 首次使用取当前数据域原有created_at，按北京时间显示日期。旧值缺失或无效明确写暂无记录，不以当前时间补造；新账号服务端日期标记尚未回读时可在下次刷新取得实际日期。
- 改名使用居中弹窗，2–12字，失败保留输入，成功同步内存快照，迟到资料响应不能回滚新名称。输入聚焦有微色阶、细边与外环。
- unlocked_easter_ids仅为未来字段约定：稳定彩蛋编号、服务端确认真实解锁。第一版未添加空标签、未迁移本机遇见记录，图鉴仍待单独设计。

## 外观与渐变

- 松绿、晴蓝、暖橙、烟紫、WZ红五套预设。WZ红种子#9F2925来自用户提供校徽截图取样，并非新增官方品牌规范。
- 模式/预设即时生效并保存。自定义拖动即时预览，通知最多约25次/秒，存储120ms合并；结束手势、关闭抽屉或离页刷入最后值。没有“取消/保存”反复试色流程。
- 自定义保留饱和度/明度平面和一条彩虹色相条；移除重复绿色滑条；整行/右侧箭头可收起，选择预设也收起，仅展开不擅自切到自定义。

## 后端与保留规则

manageFeedback为独立新增函数，原12个函数不因新模块改接口。新增user_feedback、feedback_polls、feedback_votes、feedback_limits及其test_集合，均ADMINONLY，经服务端校验身份、本人范围或正式超管权限。

反馈有请求幂等、每分钟一次/每日三条限制、正式内容安全检查；回复用revision防覆盖，已读只推进已展示的回复版本。投票使用每人每题确定性文档ID，计数及改票在同一事务提交，截止/手动结束后拒绝写入。汇总不返回投票人身份。

旧投稿/排期的本期和前两期清理不改。反馈与投票不随周清理，未实现自动归档或删除；新测试集合也没有擅自加入现有清理白名单。用户名管理、图鉴云同步及正式保留期限另议。

部署及回读证据见../deployments/2026-10-27-manageFeedback.json。当前新函数默认3秒，正式内容安全耗时及组合查询索引仍需上线前运维复核；不把测试域成功等同正式用户全链路验收。
